## 5. 기능설명서

별첨: [기능설명서.md](./기능설명서.md) (공모전 양식 PPTX 와 동일 내용, 핵심 기능 흐름도 5개 포함)

### 핵심 기능 요약

- **시간 슬라이더 추천** — 외출 가능 시간(1~6h)·출발지(충남 15시군)·반려견·출발 시각 → 반경 자동 계산 → 펫 동반 가능 + 한적한 곳 3곳 카드 추천 (거리·편도/왕복·남은 시간·한적도·검증 수)
- **한적도 점수** — 데이터랩 시군구 방문자 데이터(외지인 비율) 실측 + 시간대 가중 → 0~100 점, 카드·상세에 근거 문구 표시. 30일 예측 라인은 집중률 API 활용신청 후 연동
- **펫동반 검증 배지** — 관광공사 펫 데이터(1차) + 사용자 방문 인증(사진 EXIF 좌표 1km·7일, 서로 다른 3명, 최근 6개월) 교차 검증 → DB 트리거로 배지 자동 부여·만료
- **두루누비 산책로** — 충남 16코스 목록, 거리·소요·난이도, 경로 미리보기(카카오맵/SVG 스케치), 카카오 길찾기
- **장소 상세·후기** — 펫 정책, 시간대별 한적도, 검증 진행도, 방문 인증, 후기(별점·사진), 북마크
- **마이펫타임** — 반려견 등록, 추천 이력, 내가 쓴 후기, 저장한 장소, 이메일 알림 설정(시간·요일, 1탭 수신거부), 회원 탈퇴
- **퇴근 후 추천 이메일** — 설정한 시간·요일에 Edge 함수(pg_cron)가 추천을 생성해 발송 (발송 키 등록 후 활성화)
- **소셜 로그인·동의 관리** — 구글·카카오 로그인, 약관·개인정보·이메일 수신 동의 이력 저장

## 6. 서비스 차별성 & 발전계획

### 차별성

- **거리(km)가 아니라 "남은 시간"으로 검색** — 시간 슬라이더 하나로 반경·ETA·남은 체류시간까지 계산해 퇴근 후 결정 피로를 없앰
- **공공데이터 기반 한적도** — 한국관광공사 데이터랩 방문자 데이터를 시군구·요일 단위로 실측해 점수화, 카드마다 근거를 투명하게 표시 (30일 예측 확장 준비 완료)
- **펫동반 "검증" 배지** — 관광공사 반려동물 데이터 + 사용자 사진 EXIF 교차 검증으로 "표기는 되어 있는데 현장은 테라스만" 같은 헛걸음 방지. 배지 부여·만료가 DB 트리거·크론으로 자동화
- **두루누비 공식 코스를 반려견 산책로로 재해석** — 경로 좌표를 그대로 이어 미리보기, 카카오 길찾기 연결
- **충남 1지역 집중** — 반려동물 동반관광 조례·태안 반려동물 친화관광도시 등 정책 선도 지역을 초기 시장으로, 15개 시·군 출발지 지원

### 발전계획

| 시기 | 계획 |
|---|---|
| 단기 (~1개월) | Edge 함수 재배포·카카오 키 적용으로 실도로 ETA, 집중률 30일 예측 API 연동으로 "미래 한적도" 카드 라인 활성화, 추천 이메일 정식 발송 |
| 중기 (~3개월) | 충남 전역 POI 확대(현 4시 중심 → 15시군), 수요 강도 지수(AreaTarResDemService 등) 결합으로 한적도 정밀화, 시간대별 한적도 실측(내비·이동통신 데이터) 보강, 추천 이유 칩 클릭 시 데이터 출처 상세 |
| 장기 (6개월~) | 카카오톡 채널 알림, 펫 동반 업체 입점(펫 정책 셀프 등록·사업자 검증)과 예약/쿠폰 등 수익 모델, 강원·경북 등 타 지역 확장, 계절·날씨 데이터 결합 추천 |
| 데이터 환류 | 사용자 방문 인증·후기 데이터를 익명 통계로 정리해 관광공사 반려동물 동반여행 데이터 보완에 기여 |
