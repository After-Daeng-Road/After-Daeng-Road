### 브라우저 QA 추가 버그
- **북마크/상세 클릭 크래시** — 새 Prisma 모델 후 dev 서버가 옛 클라이언트 물고 있어 `prisma.bookmark` undefined → **서버 재시작으로 해결**(모델 추가 시 재시작 필수).
- **펫폼 숫자 앞자리0** — `value={number}`+`Number(onChange)` 커서 버그 → 문자열 상태로.
- **후기/체크인/동의 크래시** — 공용 rate-limit 헬퍼가 Upstash 빈값에서 `/pipeline` 크래시 → **fail-open**.
- **홈 북마크 새로고침 시 풀림** — 추천 카드가 `initialBookmarked=false` 하드코딩 → 자기조회로 실제 상태 반영.

## 추천 속도 최적화
- 후보 POI 최대 30개 × (getQuietness 3쿼리 + getVerifiedCount 1쿼리) = **~120 쿼리/요청** → `verifications`/`quietness_scores`/`poi_forecasts` 를 `.in('poi_id',[...])` 배치로 → **~5 쿼리**.
